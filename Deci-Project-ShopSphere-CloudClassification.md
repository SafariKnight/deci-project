# Cloud Service Classification

## Frontend Hosting — Vercel
- **Service Model**: PaaS (Platform as a Service)
- **Reason**: Vercel provides managed hosting where developers only deploy source code and Vercel handles the runtime, scaling, and infrastructure provisioning automatically.

## Backend Hosting — Vercel (Serverless Functions)
- **Service Model**: PaaS (Platform as a Service)
- **Reason**: The backend runs as serverless functions on Vercel, where the platform manages the execution environment, scaling, and infrastructure without requiring server management.

## Database — PostgreSQL on Supabase
- **Service Model**: PaaS (Platform as a Service)
- **Reason**: Supabase provides a managed PostgreSQL database where the service handles database provisioning, backups, and maintenance, while users interact only with the database instance.
